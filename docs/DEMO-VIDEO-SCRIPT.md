# Демо-видео (до 3 минут) — «как это работает»

Колоссеум просит отдельное видео продукта **не длиннее 3 минут**. Записывай экран (OBS или Win+G), голос — на английском, спокойно. Ниже план кадров. Текст — подсказка, **говори своими словами**.

| Время | Что на экране | О чём сказать |
|---|---|---|
| 0:00–0:15 | Карта JamMap, живая | Что это: телефоны, которые слышат атаки на GPS, и Solana, которая это доказывает. |
| 0:15–0:45 | Телефон (запись экрана Android): статус CLEAN SKY, график C/N0 и AGC | Приложение читает сырые данные спутников. Две цифры: сила сигнала и усиление приёмника (AGC). |
| 0:45–1:05 | Телефон в металлической коробке/фольге → статус **BLOCKED (not jamming)** | Главный трюк: при глушении AGC падает, при простом блокировании растёт. Поэтому мы не путаем карман с атакой и не шлём ложных отчётов. |
| 1:05–1:30 | Галочка TEST → **JAMMING DETECTED** → лог «signed report → accepted 1/3» | Глушилки незаконны, поэтому подмешиваем синтетическую сигнатуру. Телефон подписывает отчёт своим ключом, SOL на телефоне нет. |
| 1:30–2:00 | Терминал с симулятором + карта: зона из пунктира становится красной, «✓ CONFIRMED 3/3»; ссылка на транзакцию → Solana Explorer | Инцидент подтверждается, только когда 3 разных телефона его видят. Программа на Solana сама проверяет подпись каждого телефона через Ed25519, ретранслятор подделать отчёт не может. Фейковый отчёт мошенника так и остаётся 1/3. |
| 2:00–2:35 | Кнопка **Buy one request** или `npm run buy` → 402 → оплата USDC → риск HIGH, источник ±0.x km | Покупатель — сервер дрона. Платит за запрос через x402 в USDC: без аккаунтов и API-ключей. Получает оценку места источника. |
| 2:35–2:55 | Код: `lib.rs` (verify_prev_ed25519, quorum), README | Что построено за хакатон: программа Anchor, ретранслятор, x402 API, Android-приложение, симулятор, тесты. |

**Перед записью:**
1. `npm run demo` + сброс (`curl -X POST http://localhost:8787/v1/admin/reset`) + `npm run sim`.
2. Включи devnet (шаг 3 в RU-START-HERE), чтобы в ленте были настоящие транзакции, а не «off-chain».
3. Увеличь масштаб браузера до 125%, чтобы текст читался на видео.
